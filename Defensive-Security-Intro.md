# Defensive Security Intro

## Overview

This room introduced the fundamentals of **Defensive Security** and explained how organizations protect systems, networks, and users from cyber attacks.

Unlike Offensive Security, which focuses on attacking systems to discover vulnerabilities, Defensive Security focuses on:

* Preventing attacks
* Detecting malicious activity
* Responding to security incidents
* Recovering affected systems

The lesson also introduced important defensive security domains such as SOC, Threat Intelligence, DFIR, and Malware Analysis.

---

# Key Concepts Learned

## What is Defensive Security?

Defensive Security focuses on protecting systems and responding to cyber threats.

### Main Objectives

* Prevent intrusions
* Detect attacks
* Respond to incidents
* Minimize damage
* Recover systems securely

# Defensive Security Tasks

## User Security Awareness

Educating users about cyber security threats helps reduce attacks such as phishing and social engineering.

## Asset Management

Organizations must track and manage systems, servers, and devices to secure them properly.

## Patching and Updates

Keeping systems updated helps prevent exploitation of known vulnerabilities.

## Preventative Security Devices

### Firewall

Controls incoming and outgoing network traffic.

### Intrusion Prevention System (IPS)

Detects and blocks malicious network activity.

## Logging and Monitoring

Monitoring systems and network logs helps detect suspicious activity and unauthorized access.

---

# Security Operations Center (SOC)

A Security Operations Center (SOC) is a team responsible for monitoring systems and networks for security threats.

## SOC Responsibilities

### Vulnerability Management

Identifying and helping fix security weaknesses.

### Policy Violation Detection

Detecting activities that break organizational security rules.

### Unauthorized Activity Detection

Identifying suspicious login attempts or compromised accounts.

### Network Intrusion Detection

Detecting attacks or unauthorized access attempts on the network.

---

# Threat Intelligence

Threat Intelligence involves collecting and analyzing information about attackers and cyber threats.

## Threat Intelligence Process

1. Collect data
2. Process data
3. Analyze attacker behavior
4. Generate defensive recommendations

## Goals

* Understand attacker tactics
* Predict attacks
* Improve defensive strategies
* Build threat-informed defense systems

---

# Digital Forensics and Incident Response (DFIR)

DFIR combines investigation and response techniques used after security incidents occur.

---

# Digital Forensics

Digital forensics investigates evidence left behind after cyber attacks.

## Areas of Investigation

### File System Analysis

Examining files, deleted data, and installed programs.

### Memory Analysis

Investigating malware running in system memory.

### System Logs

Reviewing logs to identify suspicious activity.

### Network Logs

Analyzing network traffic for evidence of attacks.

---

# Incident Response

Incident Response defines the process used to handle cyber attacks and security incidents.

## Incident Response Phases

### 1. Preparation

Building teams, tools, and procedures before incidents occur.

### 2. Detection and Analysis

Identifying and investigating suspicious activity.

### 3. Containment, Eradication, and Recovery

Stopping the attack, removing threats, and restoring systems.

### 4. Post-Incident Activity

Documenting lessons learned and improving defenses.

---

# Malware Analysis

Malware analysis studies malicious software to understand its behavior and impact.

## Types of Malware

### Virus

Spreads by attaching itself to files and programs.

### Trojan Horse

Appears legitimate while hiding malicious functionality.

### Ransomware

Encrypts files and demands payment for recovery.

---

# Malware Analysis Techniques

## Static Analysis

Analyzing malware without executing it.

## Dynamic Analysis

Running malware in a controlled environment to observe behavior.
