# CIA Triad - Cyber Security Fundamentals

## What is Cyber Security?

Cyber Security is the practice of protecting systems, networks, applications, and data from unauthorized access, modification, or disruption.

The primary goal of cyber security is to protect digital information.


# CIA Triad

The CIA Triad is the foundation of cyber security.

CIA stands for:

* Confidentiality
* Integrity
* Availability

These three principles define what cyber security protects.

```text
        CIA Triad

    Confidentiality
           ▲
           │
           │
Integrity ◄┼► Availability
```

 

# Confidentiality

## Definition

Confidentiality ensures that information is only accessible to authorized users.

Unauthorized users should not be able to view sensitive information.

 

## Goal

Prevent unauthorized access to data.

 

## Examples

### Confidentiality Achieved

* Employees access only the files required for their job.
* Data is protected using passwords and encryption.

### Confidentiality Violated

* Passwords written on sticky notes.
* Private documents exposed on the internet.
* Attackers stealing login credentials.

 

## Common Controls

* Passwords
* Multi-Factor Authentication (MFA)
* Encryption
* Access Control

 

# Integrity

## Definition

Integrity ensures that data remains accurate, complete, and unaltered by unauthorized users.

Users must be able to trust the data.

 

## Goal

Prevent unauthorized modification of data.

 

## Examples

### Integrity Achieved

* Data changes only through authorized approval.
* Official records remain unchanged.

### Integrity Violated

* Exam grades changed without permission.
* Bank transaction details modified.
* Attendance records altered after submission.

 

## Common Controls

* Hashing
* Digital Signatures
* Access Controls
* File Integrity Monitoring

 

# Availability

## Definition

Availability ensures that data and services are accessible when authorized users need them.

 

## Goal

Ensure continuous access to systems and data.

 

## Examples

### Availability Achieved

* Systems remain accessible during working hours.
* Websites stay online and operational.

### Availability Violated

* Website crashes due to an attack.
* Server outage prevents users from accessing services.
* Power failure causes systems to go offline.

 

## Common Controls

* Backups
* Redundant Systems
* Load Balancing
* Disaster Recovery Plans
* Power Generators

 

# CIA Triad Summary

| Pillar          | Protects Against          | Main Goal            |
| --------------- | ------------------------- | -------------------- |
| Confidentiality | Unauthorized Access       | Keep data secret     |
| Integrity       | Unauthorized Modification | Keep data accurate   |
| Availability    | Service Disruptions       | Keep data accessible |

 

# Real-World Examples

| Situation            | CIA Pillar      |
| -------------------- | --------------- |
| Stolen Password      | Confidentiality |
| Modified Exam Grades | Integrity       |
| Website Outage       | Availability    |
| Data Leak            | Confidentiality |
| Altered Transaction  | Integrity       |
| Server Downtime      | Availability    |

 

# Importance of CIA Triad

The CIA Triad helps security professionals:

* Design secure systems
* Identify security risks
* Analyze cyber attacks
* Implement security controls
* Protect critical data

Almost every cyber security concept can be linked to one or more CIA pillars.
