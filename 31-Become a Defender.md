# Defensive Security Fundamentals

## What is Defensive Security?

Defensive Security focuses on protecting systems, networks, applications, and data from attacks.

Goal:

```text
Prevent attacks
↓
Detect attacks
↓
Respond to attacks
↓
Recover and improve security
```

Defenders are commonly called the **Blue Team**.

 

# CIA Triad and Defensive Security

Defensive Security aims to protect:

## Confidentiality

```text
Prevent unauthorized access to data
```

 

## Integrity

```text
Prevent unauthorized modification of data
```

 

## Availability

```text
Ensure systems and data remain accessible
```

 

# Defender's Responsibilities

A defender must:

* Know what exists in the environment
* Monitor systems continuously
* Identify threats
* Apply protections
* Respond to incidents

 

# Visibility

## Definition

The ability to see and monitor activity across systems.

Examples:

```text
Logs
Alerts
Network traffic
System events
```

Without visibility, defenders cannot detect attacks.

# Core Defensive Security Functions

## 1. Prevention

### Definition

Stopping attacks before they happen.

Examples:

* Firewalls
* Antivirus
* Security updates
* Access controls

Goal:

```text
Stop threats before damage occurs
```

 

## 2. Detection

### Definition

Finding suspicious or malicious activity.

Examples:

* Monitoring logs
* Security alerts
* Network monitoring

Goal:

```text
Identify attacks quickly
```

 

## 3. Mitigation

### Definition

Reducing the impact of an attack.

Examples:

* Blocking IP addresses
* Disabling accounts
* Isolating infected systems

Goal:

```text
Limit damage
```
 

## 4. Analysis

### Definition

Investigating what happened.

Sources:

* Logs
* Alerts
* Evidence
* System activity

Goal:

```text
Understand attack cause and impact
```

 

## 5. Response and Improvement

### Definition

Recovering from incidents and strengthening defenses.

Examples:

* Restore systems
* Patch vulnerabilities
* Improve monitoring
* Update security controls

Goal:

```text
Prevent future incidents
```

 

# Defender Mindset

Defenders must think like attackers.

Questions to ask:

```text
What can be attacked?
How would an attacker gain access?
What is the most valuable target?
What happens if one system is compromised?
```

 

# Key Defender Principles

## Threat Anticipation

### Definition

Predicting possible attack paths before attackers use them.

Question:

```text
What if this system is attacked?
```


## Attack Awareness

### Definition

Understanding common attacker techniques and attack chains.

Purpose:

```text
Recognize attacks early
```

 
## Risk Prioritization

### Definition

Identifying the most important systems and focusing protection efforts on them.

Purpose:

```text
Protect critical assets first
```

 

## Continuous Adaptation

### Definition

Security must constantly evolve.

Reason:

```text
Attackers change tactics
New vulnerabilities appear
Threats evolve
```

 

# Common Systems and Defenses

## Employee Devices

### Risks

* Malware
* Phishing
* Malicious downloads

### Defenses

* Antivirus
* Security updates
* User awareness training

 

## Web Server

### Risks

* Website attacks
* Unauthorized access

### Defenses

* Secure communication
* Access controls
* Firewall protection

 

## Mail Server

### Risks

* Phishing emails
* Malicious attachments

### Defenses

* Spam filtering
* Email scanning

 

## Firewall

### Definition

A security control that filters network traffic.

Purpose:

```text
Allow legitimate traffic
Block unauthorized traffic
```

 

## Internet

### Risks

* External attackers
* Malware
* Unauthorized access attempts

### Defenses

* Monitor traffic
* Restrict inbound connections
* Apply firewall rules


# Threat

## Definition

Anything capable of causing harm to systems, data, or users.

Examples:

* Hackers
* Malware
* Phishing
* Ransomware

 

# Risk

## Definition

The likelihood and impact of a threat causing damage.

Formula:

```text
Risk = Likelihood + Impact
```

 

# Security Layers

Good security uses multiple layers.

Example:

```text
Firewall
    ↓
Antivirus
    ↓
Monitoring
    ↓
Incident Response
```

If one layer fails, another can still provide protection.

 

# Blue Team

## Definition

The group responsible for defending systems and responding to threats.

Responsibilities:

* Monitoring
* Detection
* Incident response
* Security improvements

 

# Security Monitoring

Used to identify suspicious activity.

Examples:

```text
Failed login attempts
Unusual network traffic
Unexpected system changes
```

 

# Incident Response

## Definition

The process of handling a security incident.

Steps:

```text
Detect
↓
Investigate
↓
Contain
↓
Recover
↓
Improve
```

 

# Defensive Security Workflow

## Step 1: Identify Assets

Know what exists.

Examples:

* Devices
* Servers
* Applications

 

## Step 2: Assess Risks

Determine what is most valuable.

 

## Step 3: Apply Controls

Examples:

* Firewalls
* Antivirus
* Updates


## Step 4: Monitor Activity

Review:

* Logs
* Alerts
* Traffic

 

## Step 5: Respond to Threats

Contain and mitigate attacks.

 

## Step 6: Improve Security

Learn from incidents.
