# Windows Basics

## What is Windows?

Windows is a graphical operating system developed by Microsoft.

It provides:

* User Interface (GUI)
* Hardware Management
* Software Execution
* File Management
* Security Features

Windows is the most widely used desktop operating system.



# User Accounts in Windows

Windows uses user accounts to control access and permissions.

## Types of Accounts

| Account Type  | Description                                    |
| ------------- | ---------------------------------------------- |
| Guest         | Temporary access with very limited permissions |
| Standard User | Daily tasks without system-wide changes        |
| Administrator | Full control over the system                   |

### Administrator Permissions

* Install software
* Change system settings
* Manage users
* Access all files

# Windows File Structure

Windows uses a hierarchical structure.

Example:

```text
C:\
 ├── Users
 │    ├── Administrator
 │    ├── Alex
 │
 ├── Program Files
 ├── Windows
```

# File Path

A file path shows the location of a file or folder.

Example:

```text
C:\Users\Administrator\Desktop
```

### Path Breakdown

| Component     | Meaning     |
| ------------- | ----------- |
| C:            | Drive       |
| Users         | Main Folder |
| Administrator | User Folder |
| Desktop       | Subfolder   |

# Windows Defender Firewall

Windows Defender Firewall filters network traffic.


## Firewall Profiles

### Domain Profile

Used in organizations.


### Private Profile

Used on trusted networks.

Examples:

* Home Network
* Lab Network

### Public Profile

Used on untrusted networks.

Examples:

* Public Wi-Fi
* Airport Wi-Fi


# Firewall Rules

## Inbound Rules

Control traffic entering the computer.

Example:

```text
Allow Remote Desktop
```

## Outbound Rules

Control traffic leaving the computer.

Example:

```text
Allow Browser Internet Access
```


# Windows Security Best Practices

1. Keep Windows updated.
2. Install software only from trusted sources.
3. Enable Firewall.
4. Run regular scans.
5. Use strong passwords.
6. Remove unused applications.
7. Keep antivirus enabled.
